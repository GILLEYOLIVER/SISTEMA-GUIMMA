# Documentacao

Esta pasta guarda documentos auxiliares, relatorios de teste e comandos.

Os manuais operacionais principais ficam em:

```text
MANUAIS_DO_SISTEMA/
```

Arquivos mais usados:

- `docs/COMANDOS`: comandos rapidos de Git/build.
- `MANUAIS_DO_SISTEMA/09_GERAR_INSTALADORES.txt`: roteiro de geracao dos instaladores.
- `MANUAIS_DO_SISTEMA/13_SCRIPTS_GERAR_INSTALADORES_TODOS_APPS.txt`: comandos separados por app.
- `COMO_USAR_GERENCIAMENTO_LICENCAS.txt`: como inserir, ativar, bloquear e renovar licencas.
- `MANUAIS_DO_SISTEMA/14_LIMPEZA_TESTE_MAQUINA_CLIENTE_MAC.txt`: limpeza de Mac para teste como cliente.

Nao colocar aqui senhas completas, tokens Cloudflare ou arquivos `.dev.vars`.
