COMO USAR O GERENCIAMENTO DE LICENCAS
Sistema Guimma

Objetivo:

Ensinar onde inserir uma licenca, como ativar o email de um cliente, como
bloquear, renovar, consultar e liberar troca de computador.


============================================================
1. FORMA RECOMENDADA: PAINEL WEB
============================================================

Use o painel web pelo navegador:

https://sistema-guimma-licencas.sistemaguimma.workers.dev/admin

Funciona em:

- Mac.
- Windows.
- Celular.
- Tablet.
- Qualquer computador com navegador e internet.

Nao precisa instalar o app administrativo nativo para gerenciar licencas.

============================================================
3. ONDE INSERIR UMA LICENCA
============================================================

1. Abra:

   https://sistema-guimma-licencas.sistemaguimma.workers.dev/admin

2. Entre com email administrativo e senha administrativa.

3. No painel, procure o campo:

   Email do cliente

4. Digite o email que o cliente vai usar no licenciador.

Exemplo:

cliente@email.com

Esse email precisa ser o mesmo que o cliente digitara no app:

Sistema Guimma Licenca


============================================================
4. ATIVAR CLIENTE
============================================================

Use quando o cliente pagou ou quando voce quer liberar teste.

1. Digite o email do cliente no campo "Email do cliente".
2. Digite o nome do cliente, se desejar.
3. Em "Dias", coloque o prazo de liberacao.
   Normalmente use 30.
4. Clique em:

   Ativar

Resultado:

- O email fica salvo/ativo no Cloudflare.
- A validade e gravada pelo numero de dias informado.
- O cliente podera validar no app Sistema Guimma Licenca.
- A licenca fica presa a 1 computador por vez.


============================================================
5. RENOVAR CLIENTE
============================================================

Use quando o cliente pagou a mensalidade novamente.

1. Digite o email do cliente.
2. Em "Dias", coloque a quantidade que deseja somar.
   Normalmente use 30.
3. Clique em:

   Renovar

Resultado:

- A validade e aumentada.
- Se estava bloqueada/inativa, volta para ativa.


============================================================
6. BLOQUEAR CLIENTE
============================================================

Use em falta de pagamento, cancelamento ou teste encerrado.

1. Digite o email do cliente.
2. Clique em:

   Desativar/Bloquear

3. Confirme a operacao.

Resultado:

- O email continua registrado no Cloudflare.
- A licenca fica inativa/bloqueada.
- O cliente perde acesso quando o licenciador/sistema consultar o servidor.


============================================================
7. LIBERAR TROCA DE COMPUTADOR
============================================================

Use quando o cliente trocou de computador, formatou ou perdeu acesso ao
computador antigo.

1. Digite o email do cliente.
2. Clique em:

   Liberar computador

3. Confirme.

Resultado:

- A assinatura continua ativa.
- O vinculo com o computador antigo e removido.
- O cliente pode validar no computador novo.

Isso nao bloqueia pagamento e nao desativa o cliente.


============================================================
8. CONSULTAR CLIENTE
============================================================

1. Digite o email do cliente.
2. Clique em:

   Consultar

O painel mostra:

- Email.
- Nome.
- Plano.
- Status.
- Validade.
- Computador ativo.
- Nome do computador.
- Sistema operacional.
- Data de ativacao.
- Ultimo uso.


============================================================
9. TESTE PRATICO DE LICENCIAMENTO
============================================================

1. No painel web, ative um email de teste por 30 dias.
2. No computador de teste, abra:

   Sistema Guimma Licenca

3. Digite o mesmo email.
4. Clique em:

   Salvar

5. Clique em:

   Validar agora

6. Abra o Sistema Guimma.

Se a licenca estiver ativa, o sistema libera.
Se nao houver licenca ativa, o sistema deve bloquear.


============================================================
10. DIFERENCA ENTRE OS BOTOES
============================================================

Ativar:

- Cria ou reativa uma licenca para o email.

Renovar:

- Soma mais dias na validade.

Desativar/Bloquear:

- Corta acesso do cliente.

Liberar computador:

- Mantem cliente ativo, mas solta o computador antigo.

Consultar:

- Mostra o estado atual da licenca.


============================================================
11. RESUMO RAPIDO
============================================================

Para inserir uma licenca:

1. Abra o painel web.
2. Entre com o acesso administrativo.
3. Digite o email do cliente.
4. Coloque 30 dias.
5. Clique em Ativar.
6. Cliente abre o licenciador.
7. Cliente digita o mesmo email.
8. Cliente clica em Validar agora.
