GERAR INSTALADORES DO SISTEMA GUIMMA

Objetivo:

Gerar os instaladores oficiais para entregar o Sistema Guimma aos clientes.

Versao usada nos exemplos:

1.1.1

Troque a versao quando for gerar uma nova entrega.


============================================================
1. MACOS - GERAR APP + PKG + DMG
============================================================

Este comando deve ser rodado no Mac.

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

PYTHON_BIN=.venv/bin/python ./packaging/macos/build_installer.sh --version 1.1.1 --with-dmg --with-pkg

O que ele gera:

- dist/Sistema Guimma.app
- dist/Sistema Guimma Licenca.app
- dist/SistemaGuimma/CONFIGURAR_BANCO.app
- dist/SistemaGuimma/CONFIGURAR_POSTGRES.app
- dist/installers/macos/Sistema Guimma 1.1.1 macOS.pkg
- dist/installers/macos/Sistema Guimma 1.1.1 macOS.dmg

O PKG instala em /Applications:

- Sistema Guimma.app
- Sistema Guimma Licenca.app
- CONFIGURAR_BANCO.app
- CONFIGURAR_POSTGRES.app


============================================================
2. WINDOWS - GERAR INSTALADOR OFICIAL X64
============================================================

Este comando deve ser rodado no Windows.

Precisa ter:

- Python x64.
- Dependencias do projeto instaladas.
- PyInstaller.
- Inno Setup 6.

cd C:\CAMINHO\PARA\SISTEMA-GUIMMA

powershell -ExecutionPolicy Bypass -File packaging\windows\build_installer.ps1 -Python python -Version 1.1.1 -Architecture x64

O que ele gera:

- dist\Sistema_Guimma_Setup_x64.exe

O instalador Windows inclui:

- SistemaGuimma.exe
- SistemaGuimmaLicenca.exe
- CONFIGURAR_BANCO.exe
- CONFIGURAR_POSTGRES.exe
- pasta SCRIPTS
- icones oficiais


============================================================
3. WINDOWS - GERAR INSTALADOR OFICIAL X86
============================================================

Use somente se precisar atender Windows 32 bits.

Importante:

Para Architecture x86, use Python 32 bits.

cd C:\CAMINHO\PARA\SISTEMA-GUIMMA

powershell -ExecutionPolicy Bypass -File packaging\windows\build_installer.ps1 -Python python -Version 1.1.1 -Architecture x86

Saida:

- dist\Sistema_Guimma_Setup_x86.exe


============================================================
4. WINDOWS - GERAR PACOTE UNIFICADO
============================================================

Use quando quiser uma pasta final com instalador, configuradores e scripts.

cd C:\CAMINHO\PARA\SISTEMA-GUIMMA

powershell -ExecutionPolicy Bypass -File packaging\windows\build_unified_package.ps1 -Python python -Version 1.1.1 -Architecture x64

Saida:

- dist\Sistema_Guimma_1.1.1_x64\

Conteudo esperado:

- Sistema_Guimma_Setup_x64.exe
- CONFIGURAR_BANCO.exe
- CONFIGURAR_POSTGRES.exe
- SCRIPTS\
- PG_ICON.ico


============================================================
5. RELEASE COMPLETO
============================================================

Windows:

powershell -ExecutionPolicy Bypass -File packaging\release\build_release.ps1 -Python python -Version 1.1.1 -Architecture x64

Mac:

GUIMMA_VERSION=1.1.1 GUIMMA_REQUIRE_WINDOWS=0 ./packaging/release/build_release.sh


============================================================
6. COPIAR INSTALADORES PARA A MESA DO MAC
============================================================

Depois de gerar no Mac:

mkdir -p "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1"

cp -R "dist/installers/macos/Sistema Guimma 1.1.1 macOS.pkg" "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1/"

cp -R "dist/installers/macos/Sistema Guimma 1.1.1 macOS.dmg" "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1/"

Nao copie os .app soltos para a pasta de entrega.
O cliente deve usar o .pkg ou o .dmg.


============================================================
7. O QUE ENVIAR AO CLIENTE
============================================================

Cliente recebe:

- Instalador do Sistema Guimma.
- Licenciador do cliente junto no instalador.
- Configurador de banco.
- Configurador PostgreSQL quando for servidor/local.

Cliente nao recebe:

- Sistema Guimma Licencas Admin.
- Credenciais do painel web.
- Token Cloudflare.
- Arquivo .dev.vars.
- Pasta privada de administracao.
