CONFIGURAR BANCO NO SERVIDOR

Objetivo:

Criar e validar o banco do Sistema Guimma no computador servidor.

Banco:

BANCO_OPERA

Schema:

opera

Arquivo SQL inicial:

SCRIPTS/1_CRIAR_BANCO.sql

Configurador visual:

Configurar Banco de Dados

Arquivos relacionados no projeto:

- PAGINAS_DO_SISTEMA/SETUP_BANCO.py
- packaging/SETUP_BANCO.py
- configurar_postgres.py
- SCRIPTS/1_CRIAR_BANCO.sql

Passo a passo:

1. Instale o pacote do Sistema Guimma no computador servidor.

2. Ao final da instalacao, abra ou use a tela:

   Configuracao do Banco - Sistema Guimma

3. Se o PostgreSQL ainda nao existir nesse Mac, clique:

   Instalar PostgreSQL + criar banco

4. Na tela Configuracao do PostgreSQL, confirme o modo:

   - Banco Local (esta maquina), para uso em apenas este computador.
   - Servidor / Rede, para permitir acesso dos computadores clientes.

5. Informe a senha que sera usada no usuario postgres.

6. Confira os scripts preenchidos automaticamente:

   SCRIPTS/1_CRIAR_BANCO.sql
   SCRIPTS/2_CRIAR_SCHEMA.sql
   SCRIPTS/3_CRIAR_TABELAS.sql

7. Clique:

   INSTALAR POSTGRESQL + CRIAR BANCO

8. O configurador baixa/instala o PostgreSQL quando necessario, configura o
   servidor, executa a sequencia 1 -> 2 -> 3 e grava o config.json do sistema.

   Se o banco BANCO_OPERA ja existir, a etapa 1 e pulada automaticamente e o
   configurador continua nas etapas 2 e 3.

9. Para apenas salvar conexao em uma maquina cliente, use a tela Configuracao
   do Banco e informe:

   Host: IP do servidor
   Porta: 5432
   Banco: BANCO_OPERA
   Usuario: postgres
   Senha: senha definida no PostgreSQL
   Schema: opera

10. Clique para testar a conexao e depois salvar.

Arquivos de configuracao esperados:

- config.json na raiz do projeto/app.
- PAGINAS_DO_SISTEMA/config.json no ambiente de desenvolvimento.

Campos importantes do config.json:

- validated_ok: true
- mode: local ou rede
- host
- port
- dbname
- user
- password
- schema

Teste final:

1. Abra o Sistema Guimma.

2. Verifique se a tela de login abre sem erro de banco.

3. Entre com usuario administrador.

4. Abra telas que dependem do banco:

   - Modelos
   - Estoque
   - Prestadores
   - Ordens de Corte
   - Financeiro

5. Se todas carregarem, a conexao esta correta.

Problemas comuns:

- Senha do postgres incorreta.
- PostgreSQL desligado.
- Porta 5432 bloqueada.
- Banco BANCO_OPERA nao criado.
- Schema opera nao aplicado.
- Cliente tentando conectar em localhost quando deveria usar IP do servidor.
