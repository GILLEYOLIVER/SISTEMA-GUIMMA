SCRIPTS PARA GERAR INSTALADORES DE TODOS OS APPS
Sistema Guimma

IMPORTANTE:

- Comandos macOS devem ser rodados no Mac.
- Comandos Windows devem ser rodados no Windows.
- O instalador Windows precisa do Inno Setup instalado.
- O app administrativo de licencas e privado. Nao enviar para clientes.


============================================================
SCRIPT 1 - [MAC] GERAR INSTALADOR DO SISTEMA GUIMMA
============================================================

O que faz:

Gera o app e o instalador macOS do Sistema Guimma.

ESTE COMANDO E PARA MAC.

Rodar no Mac, na raiz do projeto:

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

PYTHON_BIN=.venv/bin/python ./packaging/macos/build_installer.sh --version 1.0.0 --with-dmg --with-pkg

Saidas esperadas:

dist/Sistema Guimma.app
dist/Sistema Guimma.pkg
dist/installers/macos/Sistema Guimma 1.0.0 macOS.pkg

SCRIPT 6 - [MAC] GERAR INSTALADOR PRIVADO DO ADMIN DE LICENCAS
============================================================

O que faz:

Cria uma pasta privada e um instalador .pkg para o app administrativo.
Nao enviar esse instalador para clientes.

ESTE COMANDO E PARA MAC.

Rodar no Mac:

mkdir -p "dist/Sistema Guimma Licencas Admin - Privado/macOS" "dist/Sistema Guimma Licencas Admin - Privado/windows"

ditto "dist/Sistema Guimma Licencas Admin.app" "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.app"

pkgbuild --component "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.app" --install-location "/Applications" --identifier "com.sistemaguimma.licencasadmin" --version "1.0.0" "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.pkg"

Saidas esperadas:

SCRIPT 15 - [MAC OU WINDOWS] PUBLICAR SERVIDOR CLOUDFLARE DE LICENCAS
============================================================

O que faz:

Publica o Worker de licencas no Cloudflare.
Nao e instalador, mas faz parte da entrega do sistema de licenciamento.

ESTE COMANDO PODE SER RODADO NO MAC OU NO WINDOWS.

Rodar no Mac ou Windows com Node/Wrangler configurado:

cd servidor_licencas_cloudflare

pnpm wrangler deploy

URL esperada:

https://sistema-guimma-licencas.sistemaguimma.workers.dev


============================================================
SCRIPT 16 - [MAC OU WINDOWS] APLICAR MIGRACOES DO BANCO DE LICENCAS
============================================================

O que faz:

Aplica alteracoes de tabela no banco D1 do Cloudflare.
Use somente quando existir migracao nova.

ESTE COMANDO PODE SER RODADO NO MAC OU NO WINDOWS.

Rodar na pasta do servidor Cloudflare:

cd servidor_licencas_cloudflare

pnpm wrangler d1 migrations apply sistema_guimma_licencas --remote


============================================================
ORDEM RECOMENDADA PARA VENDA
============================================================

1. Gerar instalador do sistema para o sistema operacional do cliente.

2. Garantir que o licenciador do cliente esteja compilado e incluso.

3. Se o cliente tiver servidor local, gerar/configurar CONFIGURAR_POSTGRES.

4. Testar instalacao em uma maquina limpa.

5. Cadastrar email do cliente no painel web.

6. Validar licenca no computador do cliente.

7. Fazer checklist de entrega.
