SCRIPTS PARA GERAR INSTALADORES DE TODOS OS APPS
Sistema Guimma

Arquivo de referencia para compilar os apps e gerar instaladores.

IMPORTANTE:

- Comandos de Mac devem ser rodados no macOS.
- Comandos de Windows devem ser rodados no Windows.
- O instalador Windows precisa do Inno Setup 6 instalado.
- Para Windows x86, use Python 32 bits.
- Para Windows x64, use Python 64 bits.
- O app "Sistema Guimma Licencas Admin" e privado. Nao enviar para clientes.
- Altere a versao uma vez no comando, quando for gerar uma nova entrega.


============================================================
VERSAO USADA NOS EXEMPLOS
============================================================

Versao atual sugerida pelos exemplos:

1.0.1

Se quiser gerar outra versao, troque 1.0.1 por 1.0.2, 1.0.3, etc.


============================================================
CAMINHO RAPIDO - GERAR TUDO NO MAC
============================================================

ESTE BLOCO E PARA MAC.

O que gera:

- Sistema Guimma.app
- Sistema Guimma Licenca.app
- CONFIGURAR_BANCO.app
- CONFIGURAR_POSTGRES.app
- Instalador .pkg do Sistema Guimma
- Instalador .dmg do Sistema Guimma
- Release final em dist/release/

Rodar no Terminal do Mac:

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

export VERSION=1.0.1

PYTHON_BIN=.venv/bin/python ./packaging/macos/build_installer.sh --version "$VERSION" --with-dmg --with-pkg

GUIMMA_VERSION="$VERSION" GUIMMA_REQUIRE_WINDOWS=0 ./packaging/release/build_release.sh

Saidas principais:

dist/Sistema Guimma.app
dist/Sistema Guimma Licenca.app
dist/SistemaGuimma/CONFIGURAR_BANCO.app
dist/SistemaGuimma/CONFIGURAR_POSTGRES.app
dist/installers/macos/Sistema Guimma 1.0.1 macOS.pkg
dist/installers/macos/Sistema Guimma 1.0.1 macOS.dmg
dist/release/Sistema_Guimma_1.0.1/


============================================================
CAMINHO RAPIDO - GERAR TUDO NO WINDOWS
============================================================

ESTE BLOCO E PARA WINDOWS.

O que gera:

- Sistema_Guimma_Setup_x64.exe

- CONFIGURAR_BANCO.exe
- CONFIGURAR_POSTGRES.exe

powershell -ExecutionPolicy Bypass -File packaging\release\build_release.ps1 -Python python -Version $env:GUIMMA_VERSION -Architecture x64

Saidas principais:

dist\release\Sistema_Guimma_1.0.1\

============================================================
ORDEM RECOMENDADA PARA ENTREGA A CLIENTE
============================================================

1. Gerar instalador do sistema no sistema operacional do cliente.

2. Confirmar que o licenciador do cliente esta incluso no instalador.

3. Se houver servidor local, gerar ou usar CONFIGURAR_POSTGRES.

4. Instalar PostgreSQL e banco no servidor/local pelo configurador.

5. Instalar Sistema Guimma nas estacoes.

6. Cadastrar email do cliente no painel web de licencas.

7. Validar licenca no computador do cliente.

8. Testar abertura do Sistema Guimma, banco, estoque, prestadores e fluxo de corte.


============================================================
RESUMO DO QUE ENVIAR AO CLIENTE
============================================================

Cliente Mac:

- Sistema Guimma 1.0.1 macOS.pkg ou .dmg
- Instrucoes de instalacao
- Email cadastrado na licenca

Cliente Windows:

- Pasta dist\Sistema_Guimma_1.0.1_x64\ ou ZIP final
- Sistema_Guimma_Setup_x64.exe
- CONFIGURAR_POSTGRES.exe quando a maquina for servidor
- SCRIPTS\ quando for configurar banco do zero
- Email cadastrado na licenca

Privado, nao enviar ao cliente:

- Sistema Guimma Licencas Admin
- Token do Cloudflare
- Senha do painel web
