SCRIPTS PARA GERAR TODOS OS APPS E INSTALADORES
Sistema Guimma

Versao dos exemplos:

1.1.1

IMPORTANTE:

- Comandos [MAC] rodam no Mac.
- Comandos [WINDOWS] rodam no Windows.
- Windows precisa do Inno Setup 6.
- Para Windows x86, use Python 32 bits.
- O app administrativo de licencas e privado. Nao enviar ao cliente.


============================================================
SCRIPT 1 - [MAC] SISTEMA GUIMMA COMPLETO
============================================================

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

PYTHON_BIN=.venv/bin/python ./packaging/macos/build_installer.sh --version 1.1.1 --with-dmg --with-pkg

Gera:

- dist/Sistema Guimma.app
- dist/Sistema Guimma Licenca.app
- dist/SistemaGuimma/CONFIGURAR_BANCO.app
- dist/SistemaGuimma/CONFIGURAR_POSTGRES.app
- dist/installers/macos/Sistema Guimma 1.1.1 macOS.pkg
- dist/installers/macos/Sistema Guimma 1.1.1 macOS.dmg


============================================================

SCRIPT 5 - [MAC] APP ADMINISTRATIVO PRIVADO
============================================================

.venv/bin/python -m PyInstaller SistemaGuimmaLicencasAdmin.spec --noconfirm

Gera:

- dist/Sistema Guimma Licencas Admin.app


============================================================
SCRIPT 6 - [MAC] PKG DO APP ADMINISTRATIVO PRIVADO
============================================================

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

mkdir -p "dist/Sistema Guimma Licencas Admin - Privado/macOS"

ditto "dist/Sistema Guimma Licencas Admin.app" "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.app"

pkgbuild --component "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.app" --install-location "/Applications" --identifier "com.sistemaguimma.licencasadmin" --version "1.1.1" "dist/Sistema Guimma Licencas Admin - Privado/macOS/Sistema Guimma Licencas Admin.pkg"

============================================================

============================================================
SCRIPT 14 - [MAC] COPIAR INSTALADORES PARA A MESA
============================================================

cd /Users/gilleydeoliveiraguimaraes/PycharmProjects/SISTEMA-GUIMMA

mkdir -p "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1"

cp -R "dist/installers/macos/Sistema Guimma 1.1.1 macOS.pkg" "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1/"
cp -R "dist/installers/macos/Sistema Guimma 1.1.1 macOS.dmg" "$HOME/Desktop/Instaladores Sistema Guimma 1.1.1/"

Nao copie .app solto para a pasta de entrega.
O cliente deve instalar pelo PKG ou abrir o DMG.
