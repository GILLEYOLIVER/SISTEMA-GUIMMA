INSTALAR POSTGRESQL NO SERVIDOR

Objetivo:

Preparar o computador servidor onde ficara o banco de dados do Sistema Guimma.

Quando usar:

Use este roteiro apenas no computador que vai guardar o banco de dados.
Em redes com varios computadores, normalmente apenas um computador recebe o
PostgreSQL. As outras maquinas recebem apenas o sistema e apontam para o IP
do servidor.

Banco usado pelo sistema:

BANCO_OPERA

Schema usado pelo sistema:

opera

Porta padrao:

5432

Usuario comum:

postgres

Senha:

Use a senha definida na instalacao do PostgreSQL. Nao escreva senha real em
manual enviado para cliente.

Windows:

1. Instale o Sistema Guimma pelo instalador oficial.

2. Abra no Menu Iniciar:

   Preparar PostgreSQL e Banco

3. Se a instalacao automatica do PostgreSQL nao estiver disponivel no Windows
   do cliente, baixe e instale o PostgreSQL oficial manualmente.

4. Durante a instalacao do PostgreSQL:

   - Defina a senha do usuario postgres.
   - Mantenha a porta 5432, se possivel.
   - Anote a senha em local seguro.

5. Depois da instalacao, rode o configurador do servidor:

   CONFIGURAR_POSTGRES.exe

6. Execute como administrador.

7. Use a opcao de configuracao local/servidor.

8. Execute os scripts na sequencia:

   1_CRIAR_BANCO.sql
   2_CRIAR_SCHEMA.sql
   3_CRIAR_TABELAS.sql

9. Permita acesso de rede quando o banco for usado por outros computadores.

macOS:

1. Instale o pacote:

   Sistema Guimma 1.1.1 macOS.pkg

2. Ao final da instalacao, a tela Configuracao do Banco sera aberta.

3. Se o Mac for o servidor/local e o PostgreSQL nao existir, clique:

   Instalar PostgreSQL + criar banco

4. Na tela Configuracao do PostgreSQL, informe a senha que sera usada no
   usuario postgres.

5. Clique:

   INSTALAR POSTGRESQL + CRIAR BANCO

6. O configurador baixa o PostgreSQL oficial 18.4 para macOS, instala na
   porta 5432, detecta o psql, executa os scripts 1 -> 2 -> 3 e salva a
   conexao do Sistema Guimma.

7. Se for servidor de rede, escolha Servidor/Rede antes da preparacao para
   liberar o acesso dos computadores clientes.

8. Se BANCO_OPERA ja existir por uma tentativa anterior, o configurador pula
   a criacao do banco e continua aplicando schema e tabelas.

Observacao importante:

A senha do usuario postgres deve ser definida no momento da preparacao do
servidor. Nao deixe senha fixa em manual entregue para cliente.

Configuracao de rede:

Para computadores clientes acessarem o servidor, o PostgreSQL precisa aceitar
conexoes na rede.

Verifique:

- postgresql.conf permitindo listen_addresses adequado.
- pg_hba.conf permitindo o intervalo de IPs da rede local.
- Firewall liberando a porta 5432.

Exemplo de rede:

Servidor:

192.168.1.10

Clientes:

192.168.1.20
192.168.1.21
192.168.1.22

Nesse caso, os clientes devem apontar para:

host: 192.168.1.10
porta: 5432
banco: BANCO_OPERA

Checklist do servidor:

- PostgreSQL instalado.
- Servico PostgreSQL ativo.
- Porta 5432 liberada.
- Banco BANCO_OPERA criado.
- Schema opera criado/aplicado.
- Usuario e senha testados.
- Conexao local funcionando.
- Conexao de uma estacao da rede testada.
